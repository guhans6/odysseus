# Agent Instructions and Repository Rules

This repository is a fork of the Odysseus project. All AI agents and developers working on this codebase must adhere to the rules outlined below.

## Repository Setup

* **Origin Remote**: `https://github.com/guhans6/odysseus` (this fork)
* **Upstream Remote**: `https://github.com/pewdiepie-archdaemon/odysseus` (original repository)

## Branching and Commit Rules

* **Do Not Commit Directly to Default Branches**: Never commit changes directly to the `main` or `dev` branches.
* **Always Use Feature Branches**: For any bug fix, feature, or improvement, create a new branch from `dev` (e.g., `fix/bug-description` or `feature/feature-name`).
* **Keep Changes Clean**: Keep commits small, descriptive, and focused on a single issue or feature.

## Syncing with Upstream

To pull the latest updates from the upstream repository and resolve conflicts:

1. Fetch the latest changes from upstream:
   ```bash
   git fetch upstream
   ```
2. Switch to your active feature/working branch or local branch:
   ```bash
   git checkout <branch-name>
   ```
3. Merge the upstream changes:
   ```bash
   git merge upstream/dev
   ```
4. Resolve any conflicts, commit the resolved changes, and push to your origin fork.
